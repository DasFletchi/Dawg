# Source Sans 3

Regular and Semibold TrueType files from Adobe's official Source Sans release branch:

https://github.com/adobe-fonts/source-sans/tree/release/TTF

Bundled in the desktop binary so typography does not depend on the host's font installation. Font files are unmodified and distributed under the SIL Open Font License in LICENSE.md. Console output uses the host's monospace font.
